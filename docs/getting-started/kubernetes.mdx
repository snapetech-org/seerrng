# Kubernetes
:::warning
This method is not recommended for most users. It is intended for advanced users who are using Kubernetes.
:::

:::info
All official Seerr charts are cryptographically signed and include a verified [Software Bill of Materials (SBOM)](https://cyclonedx.org/).

To confirm that the chart you are using is authentic and unmodified, please refer to the [Verifying Signed Artifacts](/using-seerr/advanced/verifying-signed-artifacts#verifying-signed-helm-charts) guide.
:::

## Installation
```console
helm install seerr oci://ghcr.io/snapetech-org/seerrng/seerr-chart
```
Helm values can be found in the SeerrNG repository under [charts/seerr-chart/README.md](https://github.com/snapetech-org/seerrng/tree/main/charts/seerr-chart).

## Additional Kubernetes resources

Set `extraResources` when a SeerrNG installation needs related Kubernetes objects managed by the same Helm release. The default is an empty list, so existing chart installs render no additional resources. Each entry must be one Kubernetes resource object with `apiVersion`, `kind`, and `metadata`; Helm templates in string values can reference this chart's values and named templates.

```yaml
extraResources:
  - apiVersion: v1
    kind: ConfigMap
    metadata:
      name: '{{ include "seerr.fullname" . }}-operations'
    data:
      owner: media-operations
```

Helm manages these objects with the SeerrNG release during upgrades and removal. Use only manifests you trust; these entries can create any resource your Helm credentials are allowed to manage. Consult your cluster policy and the target resource's API before applying them.

## Temporarily stop SeerrNG for maintenance

Chart version `1.0.138` and newer supports `replicaCount: 0` for storage
migrations, backups, or other maintenance that requires the application to be
stopped. The chart retains the configuration claim while no pod is running.
Set the count back to `1` when maintenance is complete. SeerrNG is a single
instance application, so the chart rejects values outside `0` and `1`.

```console
helm upgrade seerr oci://ghcr.io/snapetech-org/seerrng/seerr-chart --version 1.0.138 --reuse-values --set replicaCount=0
# Perform the maintenance after the StatefulSet reaches zero pods.
# When maintenance is complete, restore one pod:
helm upgrade seerr oci://ghcr.io/snapetech-org/seerrng/seerr-chart --version 1.0.138 --reuse-values --set replicaCount=1
```

Verify the signature with [cosign](https://docs.sigstore.dev/cosign/system_config/installation/) (replace [tag], with the TAG you want to verify) :
```console
cosign verify ghcr.io/snapetech-org/seerrng/seerr-chart:[tag] --certificate-identity-regexp="https://github.com/(snapetech|snapetech-org)/seerrng/.github/workflows/helm.yml@refs/heads/main" --certificate-oidc-issuer=https://token.actions.githubusercontent.com
```
