# Global Search

Global Search brings results from SeerrNG's enabled media catalogs into one
place. Movie and TV results, people, music, books, authors, comics, and
magazines keep their media-specific result details and actions.

TMDB movie collections appear with the other results on the **All** search
view. Select a collection to open its collection page, where SeerrNG shows its
movie members and the existing collection request and playback actions.
Collection matches are paginated with the other global results. Adult matches
follow the administrator's TMDB adult-content setting. Because TMDB's
collection search does not include member-level maturity ratings, users with a
movie maturity limit do not see collection matches in Search.

Category tabs, result filters, sorting, and the current query are reflected in
the search URL, so the view can be revisited or shared. Search only queries
catalogs that are available to the signed-in user and enabled by the
administrator.

The collection search path adapts [Seerr PR #3430](https://github.com/seerr-team/seerr/pull/3430)
to SeerrNG's existing cross-media search and collection workflows.
