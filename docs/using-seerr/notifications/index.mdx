## Setting Up Notifications

Simply configure your desired notification agents in **Settings -> Notifications** in the Seerr web UI.

Users can customize their notification preferences in their own user notification settings.

## Notification language

Media-request event titles and follower availability notices use the language
selected for each notification delivery. Discord can use the notified user's
profile language when **Use user locale** is enabled; other agents use their
configured language where available. The configurable webhook uses the
server's default language. Messages without a translation use English.

Titles cover Movie, Series, Music, Book, Comic, Magazine, Adult Scene, and
Sports requests. Movie and Series titles also distinguish 4K requests. This
adapts the notification-title localization approach in Seerr
[PR #3421](https://github.com/seerr-team/seerr/pull/3421) to SeerrNG's
per-agent delivery and durable notification queue.

## Follow a movie or series request

When another user has an active request for a movie or series, the title's
details page shows **Notify Me When Available**. Selecting it adds a private,
one-time subscription for your account. It does not create another request,
change who requested the title, or expose that user's identity in your notice.

When the request becomes available, SeerrNG sends the notice through the
notification agents enabled for your account and the **Media Available** event
you have selected in your notification preferences. The notice links to the
movie or series details page. You can turn the subscription off from that page
before the title becomes available; after the notice is queued, the subscription
is removed automatically.

The control appears only while another user's request is active. To receive the
notice, configure at least one notification agent and enable **Media Available**
for that agent in your [notification settings](../settings/notifications.mdx).

## Requesting New Notification Agents

If we do not currently support your preferred notification agent, feel free to [submit a feature request on GitHub](https://github.com/snapetech-org/seerrng/issues). However, please be sure to search first and confirm that there is not already an existing request for the agent!
