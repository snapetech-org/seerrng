When QuestarrNG supplies game content, Lumen shows PC game editions and
add-ons. Select an edition or request missing add-ons even if you already
own the base game.
Open request history directly after submitting. It shows the selected edition
or add-ons by name when the catalog has them, with IGDB IDs as a fallback.

Game Finder supports filtered QuestarrNG searches, including excluded themes,
and lets you save searches and opt into notifications for new matches.
