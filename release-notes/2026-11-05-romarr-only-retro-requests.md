Retro and Modern game discovery and requests work with ROMarrNG alone when an older configuration retains the default QuestarrNG catalog choice. SeerrNG uses ROMarrNG's IGDB catalog when QuestarrNG is unconfigured, while preserving explicit DAT selections and configured QuestarrNG catalogs. PC game requests still use QuestarrNG.
