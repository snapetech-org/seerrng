Administrators can restrict book languages in Settings → Metadata Providers. Leave the list empty for existing unrestricted behavior. Search and discovery honor the selected languages, and ebook/audiobook requests verify and pin a matching destination edition. Unknown or disallowed edition languages cannot be requested or dispatched; destinations without edition-language verification, including Bindery and ReadMeABook, are blocked while the restriction is enabled. Existing library files are retained.
