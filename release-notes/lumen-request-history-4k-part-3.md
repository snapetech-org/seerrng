Movie request links prefer the 4K playback copy when it is available to the viewer, including through bundled redirects. A 4K movie bookmark explains when 4K playback is unavailable while retaining other available playback controls. An open 4K movie bookmark refreshes a pending or processing copy while the page is visible, so the 4K Watch link appears when the copy arrives.
