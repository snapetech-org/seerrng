Search now includes a Releases scope alongside catalog results. Use it to search configured Prowlarr indexers and send a selected release to Prowlarr's download client. Release searches remain explicit, and sending a release does not create or change a SeerrNG request. The old Indexer Search link redirects to the new scope. Audiobook searches also include matching titles from a configured ReadMeABook service, where users can submit requests and review their request status.
