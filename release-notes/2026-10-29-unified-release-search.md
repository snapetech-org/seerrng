Search now brings catalog discovery, available titles, requests, and manual
Prowlarr release searches together on one page. Its All, Library, Requests, and
Releases scopes keep the query while switching tasks. Library searches titles
SeerrNG marks available or partially available, including available software;
it does not search a user's personal media-server or tracking-account library.
Release searches remain explicit, and sending a selected result does not create
or change a SeerrNG request. The old Indexer Search link redirects to Releases.

Audiobook searches include matching titles from a configured ReadMeABook
service. Music results offer a SongID handoff with the query prefilled; it does
not start an identification job.
