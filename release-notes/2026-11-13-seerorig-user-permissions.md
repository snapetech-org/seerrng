## SeerrOrig user permissions

The permission editor remains the primary content in upstream order. SeerrNG's age restriction and per-service request grants remain available in a collapsed extension section in SeerrOrig; the SeerrNG theme keeps them expanded.

Source: [Seerr v3.5.1](https://github.com/seerr-team/seerr/commit/564bfb08b54caa374bddaf820abfd226e5e69151) by [@gauthier-th](https://github.com/gauthier-th). They contributed the source to upstream Seerr; SeerrNG independently adapted the editor presentation while preserving existing authorization behavior.
