Lumen adds a Movie and TV management sheet for request managers. It brings
request and download context together with safe links to the configured
service. Administrators can review verified library copies before deletion or
clear stale availability using the server's fresh confirmation token.
Request managers can also delete one selected request after reviewing its
confirmation; SeerrNG cleans up active work and request history.
Administrators see Plex/Tautulli play counts and Jellystat playback totals
when the matching service returns data.
The sheet also includes the permission-aware title Blocklist control and issue
history. Issue managers can close open issues while retaining their history,
or permanently delete the title's issues and comments after confirmation.
