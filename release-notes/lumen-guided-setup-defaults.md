Lumen's guided setup now lets administrators choose default request access,
global 4K availability, new-user 4K permission, and partial TV season requests.
Settings are checked against a fresh readback before setup advances, and the
step can be skipped.

The setup review also summarizes enabled request types and media libraries,
separating required setup from optional service readiness.

Request service recommendations now use SeerrNG's default enabled categories
when the settings response omits category overrides.
