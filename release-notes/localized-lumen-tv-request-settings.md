Lumen’s TV Request Settings page now translates the season-watch policy, approval queue, and Episode Queue controls using SeerrNG’s locale catalog. Arabic Episode Queue counts and manager dropdown options use Arabic dual and few forms; French dropdown options are localized too. Failed Episode Queue saves keep the selected value available for retry and show an Episode Queue-specific error.
