Create an independent theme from any installed design with
`interface-theme:create`, then validate, inspect and package it without building
the server. Packaging also writes a SHA-256 checksum file. Custom stylesheets can select
the native Persius layout through their manifest. The authoring guide and
community submission form explain how to test, install, update and share themes
without a UI-rewriting proxy.
