Lumen now lets each user choose a display language in Account Settings. The selection is saved with the account and applies to the desktop sidebar and mobile tabs, profile fields, preferred media languages, watchlist controls, account type and role, streaming subscriptions, card title preferences, and theme override controls. Some account actions and most other Lumen areas still need localization.
