SeerrOrig now keeps Seerr's Discover, Movies, Series, Requests, Blocklist, Issues, Users, and Settings links in upstream order. SeerrNG-only destinations remain available under a collapsible More section. The header and Discover home follow Seerr's upstream composition and default palette, while SeerrNG's existing branding stays in place. The settings navigation follows the upstream tab set and spacing, with fork-specific settings accessible under More settings. Search now matches upstream's results layout, and the Requests page uses upstream's primary filter controls; fork categories and advanced filters remain available under More. Movie, series, and collection detail pages follow Seerr's backdrop, responsive media header, metadata hierarchy, collection presentation, and cast/movie sliders. Person pages keep the upstream profile hierarchy and media filter; SeerrNG's additional controls remain available under More. Issues now use upstream's heading, primary filters, movie/TV cards, empty state, and pagination; movie and TV issue links open upstream's detail-page layout. SeerrNG's extended issue filters and fork-only issue detail features remain available under More issue filters or their existing inline view. User profiles use the upstream quota-card and media-slider hierarchy, with SeerrNG's extra quota and watchlist categories available in collapsed sections. The Users management page now follows upstream's action/search/sort toolbar, sortable table, selection controls, and row proportions in the shared scrollable table; SeerrNG's extra user filters and TV queue tools remain available under More.

SeerrNG independently adapted these Seerr v3.5.1 presentation patterns from the [upstream source snapshot](https://github.com/seerr-team/seerr/tree/564bfb08b54caa374bddaf820abfd226e5e69151), prepared for upstream Seerr by [@gauthier-th](https://github.com/gauthier-th). This credits work to the upstream project and does not imply that the author contributed to or endorsed SeerrNG.
