SeerrOrig now keeps Seerr's Discover, Movies, Series, Requests, Blocklist, Issues, Users, and Settings links in upstream order. SeerrNG-only destinations remain available under a collapsible More section. The header and Discover home follow Seerr's upstream composition and default palette, while SeerrNG's existing branding stays in place. The settings navigation follows the upstream tab set and spacing, with fork-specific settings accessible under More settings. Search now matches upstream's results layout, and the Requests page uses upstream's primary filter controls; fork categories and advanced filters remain available under More. Movie, series, and collection detail pages follow Seerr's backdrop, responsive media header, metadata hierarchy, collection presentation, and cast/movie sliders. Person pages keep the upstream profile hierarchy and media filter; SeerrNG's additional controls remain available under More. Issues now use upstream's heading, primary filters, movie/TV cards, empty state, and pagination; SeerrNG's extended issue filters remain available under More issue filters.
