Administrators can customize the built-in Discover Studios shelf by adding companies with their TMDB ID, reordering or removing entries, and restoring the default list. The same editor now manages the built-in Networks shelf. This feature independently adapts [upstream Seerr PR #3571](https://github.com/seerr-team/seerr/pull/3571), suggested by [@kieckhafer](https://github.com/kieckhafer).
