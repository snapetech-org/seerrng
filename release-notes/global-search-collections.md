SeerrNG global Search now includes TMDB movie collections alongside its existing cross-media results. Collection results use the existing SeerrNG detail, request, and playback flows. Adult-content settings are respected; collection matches are omitted for users with a movie maturity limit because TMDB's collection-search response does not include member ratings. This adapts Seerr [PR #3430](https://github.com/seerr-team/seerr/pull/3430).
