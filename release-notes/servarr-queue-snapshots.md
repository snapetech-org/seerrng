SeerrNG now waits for monitored-download refreshes and reads validated, paginated Servarr queue snapshots. Each official Servarr service can set its own Download Queue Size (10–10,000 items; default 1,000) for progress tracking. Queue recovery and intervention continue to require a complete snapshot within their safety bound.
