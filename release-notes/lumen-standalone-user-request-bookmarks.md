Standalone Lumen preserves the requester from the path of a Classic user request bookmark, even if the link contains conflicting requester filters. Bundled request bookmarks retain title searches and explicit book formats when opening Lumen. Bundled request bookmarks keep Lumen’s sort order, selected tab, and software filters when opening from an older request URL.
